# Playroom · Interactive classroom games

**Playroom** is one web app with interactive, game-based lessons for **Grades 1–10**.

| Level | Grades | Subjects |
|---|---|---|
| 🌈 Primary | 1–6 | English, Maths, Science |
| 🎓 Secondary | 7–10 | English, Biology, Chemistry, Physics, Algebra, Geometry, Trigonometry, Statistics |

- 📷 Webcam games: students answer with their hands (hand tracking runs in the browser).
- 🏆 Team games, quizzes, word games and mini experiments.
- ➗ New maths questions every time, with diagrams drawn on the page.
- ✏️ Teachers can edit the homepage and add their own topics (full version).

## Trial and full version

Everyone can use the **trial** straight away: 6 games and 3 topics in every subject.

To unlock **every game and topic**, enter a **full-version code** (🔑 button on the home screen or in the yellow trial bar):

- Primary codes start with `PRI-` and unlock the Primary subjects.
- Secondary codes start with `SEC-` and unlock the Secondary subjects.

The code is saved in the teacher's browser, so it only needs to be entered once on each computer. "Remove code" on the home screen clears it (useful on shared computers).

To get a code, email **waynetolomia@gmail.com**.

## Hosting on GitHub Pages

1. Upload `index.html` (and this README) to the repository.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
3. After a minute the Playroom is live at `https://<your-username>.github.io/<repository>/`.

Use Chrome or Edge on a laptop with a webcam for the hand-tracking games. The page needs internet the first time a webcam game starts (it loads Google MediaPipe).
